# PORTFÓLIO CINEMATOGRÁFICO — MATHEUS BRAGA

## Como abrir
Abra o arquivo `index.html` no navegador.

## Onde trocar as informações
- Nome/títulos/textos: `index.html`
- Visual, cores e responsividade: `style.css`
- Animações/interações: `script.js`

## Importante
O projeto usa imagens demonstrativas do Unsplash. Para o portfólio final, substitua as URLs `.media-a`, `.media-b`, `.media-c`, `.media-d` no `style.css` por thumbnails reais dos trabalhos.

Troque também:
- WhatsApp em `https://wa.me/5500000000000`
- Email `contato@matheusbraga.com`
- Links de Instagram, YouTube e Vimeo
- Números da seção de estatísticas

## Hospedagem grátis
Você pode publicar gratuitamente em GitHub Pages, Cloudflare Pages, Netlify ou Vercel.
